Create a complete professional web application called:

# LifeOS – Personal Life Management System

I want a comprehensive personal web platform that helps me manage my daily life, religious activities, education, fitness, skill development, goals, and achievements.

The application must work on both desktop and mobile devices, support full data persistence in a database, and have a modern, elegant, user-friendly design with both dark mode and light mode.

The platform should feel like a complete life operating system, not just a task manager.

## General Requirements

* Full Arabic language support.
* Full RTL (Right-to-Left) support.
* Modern UI inspired by Notion, Todoist, and Google Calendar.
* User authentication (Sign Up / Login).
* Permanent database storage.
* Data synchronization across devices.
* Responsive design for desktop, tablet, and mobile.
* In-app notifications.
* Interactive charts and analytics.
* Central dashboard showing key life metrics.
